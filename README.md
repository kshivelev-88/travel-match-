# Travel Match

Адаптивный сайт для подбора путешествий по интересам, бюджету, документам, составу группы и аренде автомобиля.

## Публикация через GitHub Pages
1. Откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch.
3. В качестве Branch выберите `main`, папку `/ (root)`, нажмите Save.
4. Дождитесь завершения публикации. Сайт будет доступен по адресу https://kshivelev-88.github.io/travel-match-/

## Важно
Рейтинги и суммы бюджета в текущей версии демонстрационные. Сайт не подключён к поставщикам авиабилетов, гостиниц или проката автомобилей. Визовые подсказки не являются юридической консультацией и требуют проверки по официальным источникам для каждого путешественника.
